## P0 · 服装迁移到雕刻网格

更新：体表求交加速、网格关节定位和体型变更后的服装重拟合已实现，见 [3D 回归记录](3d-mannequin-regressions.md)。上装肩缝/腋下、领口收边、裤装裆缝和围巾闭环已修复，见 [服装接缝回归](garment-seam-regressions.md)；多层叠穿仍待完善。以下为原始问题背景。

**为什么必须做**：现在身体已经是雕刻网格，但**服装壳仍拟合在 SDF 人体上**——
衣服是照着另一具身体算出来的，穿上去必然错位。
不做完，试穿这个核心功能在网格上是废的。

**做法**：服装壳的拟合靠「从身体轴心向外投射射线求表面半径」。
把这条射线的求交目标从 SDF 的 `raySurface()` 换成对网格做 raycast
（three.js `Raycaster`）。抽一个 `SurfaceQuery` 接口，
SDF 与网格各实现一份，服装代码不用改。

**完成后可删**：`packages/tryon-engine/src/sdf.ts`、`surface-nets.ts`、
`body.ts` 里的几何生成部分——它们只为 SDF 人体服务。
`body.ts` 的骨架（`buildSkeleton` / `limbRadiusAt`）对重拟合还有用，保留。

## P1 · 给网格绑骨架，支持多姿势

**为什么是绑骨架而不是顶点变换**：我尝试过用「绕肩关节旋转手臂顶点」
把 A 字改成自然下垂，**反复失败**：
- 按「离肩距离」加权 → 指尖落在衰减区间里，手指只转一半，扎进胯部
- 按「离哪条轴更近」分类 → 胸部离躯干轴比离手臂轴更远，被判成手臂，胸被拖塌
- 按「绝对手臂管半径」分类 → 肩部 `along <= 0` 是硬切，**上臂从肩膀撕脱**

根因：靠**几何位置**判断顶点归属，边界必然在肩部产生断裂。
只要引入任何阈值平面，就一定有撕裂。

**正解**：给网格绑骨架（skeleton + skinning weights）。
换姿势 = 旋转骨骼、按权重蒙皮，**不会有硬边界**，任意姿势都能加。
MakeHuman 的网格本就是为绑定设计的（干净四边形拓扑、有 UV）。

**候选资产**：MakeHuman 的默认骨架与权重在其主程序包内（本网络取不到），
需要另找 CC0 的 rig，或自行用 Blender 绑（Blender 也要过 GitHub，需另找镜像）。
**这是需要先解决的前置问题。**

**过渡方案**：在绑好骨架之前，接受 A 字站姿。A 字对试穿反而更有利——
腋下空间大，衣服不容易穿插。

## P2 · 网格打包体积

2.5MB 纯 OBJ 文本（男 1.17MB + 女 1.30MB），而**微信小程序主包上限 2MB**。

方向（按优先级）：
1. 转 GLB + Draco 压缩，通常能压到原体积的 15–25%
2. 按性别分包，进试穿页时再拉取
3. 若仍不够，简化脚趾/耳朵等试穿场景看不清的部位

**移动端另有代价**：首次加载要下 1.2MB，弱网下要等几秒。

## P3 · 重拟合的面片感

大腿与胯部近看有轻微面片感，来自 `mesh-body.ts` 的径向重拟合增益。
目前是「按肢体段径向缩放」，段与段之间用 smoothstep 混合，
但躯干的分段线性增益（胯/腰/胸三点）在大幅改动体型时会产生折痕。

方向：把增益函数从分段线性改成 C1 连续的样条。

## 已放弃 / 不再做

- **SDF 程序化人体**：分辨率墙。肌肉分界沟宽 3–6mm，而体素是 10.9mm，
  要分辨需 1.4 亿角点、单次重建两分多钟。手指在 10.9mm 下会糊成连指手套。
- **解剖细节层（骨性标志与肌间沟）**：同属 SDF 路线的产物，
  换成雕刻网格后不再需要。代码保留但默认关闭（`ENABLE_ANATOMICAL_DETAILS`）。
- **头身比预设（写实/动漫/8 头身）**：已移除。它更像风格滤镜而非建模依据。
